# Gabrezo

Tools that run on your machine — local by default, no account required.

Our first release is **Background Remover for Figma**: the free tier runs 100% locally
in your browser — no sign-in, no credits, no uploads. Pro ($12 once) adds cloud cutout
for the hard edges (hair, fur, glass).
